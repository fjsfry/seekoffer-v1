# 桌面端全页面 UI 修复与验收 · 2026-10-09

## 范围与边界

基于桌面端 0.2.28 的隔离分支 `codex/desktop-recovery-20261009`，检查全部申请、日程与提醒、导师联系、通知库、院校库、资源中心、帮助与反馈，以及设置的五个分类。保留现有信息架构、品牌色与用户数据模型。

本轮仅修复和验证本地源码与桌面前端构建：未修改版本号、未推送提交、未发布更新、未覆盖用户已安装的应用，未触及主工作区的其他改动。

## 修复内容

1. **更新提示**：提示组件实际是主壳的兄弟节点，之前依赖主壳内部样式，导致固定定位与布局缺失。现在拥有独立的浮层样式，右上角显示，操作按钮和关闭按钮分别定位；与左下角普通反馈不重叠。
2. **更新反馈与模态**：设置页直接展示更新状态，不再同时显示重复的更新浮层；发现新版本和下载完成不再额外叠加成功提示。重启确认框保留原按钮节点，取消后待按钮重新可见再恢复键盘焦点；实际安装仍需确认。
3. **设置**：切换分类恢复该面板的顶部位置；高缩放下的免打扰时间输入分行显示，避免控件挤出边框。
4. **全局弹窗**：搜索和快捷键对话框按缩放后的可用视口限制高度，内部列表可以滚动，标题和关闭操作保持可达。
5. **日程与导师**：收紧小窗口标题与工具栏的留白，标题保持左对齐；分类按钮适度分列，避免占满首屏；日程筛选、分类与优先级弹层统一换算缩放坐标并约束四个方向。手动新增申请的按钮图标不再单独折行。
6. **院校与通知**：院校筛选弹层在放大时仍留在视口内；修复院校标题和工具栏被纵向挤压的问题；通知筛选在中等内容宽度使用两列。通知详情使用与桌面其他页面一致的骨架屏、异常状态及标题字号。
7. **次级工具内页**：GPA 工具移除固定网格轨道对内容的挤压，汇总自然排列；窄内容区五个标签按 3+2 分行，保留完整文字。“即将截止”页的标题、筛选与分组改为自然高度，避免高缩放时副标题越框、筛选被下一块覆盖。未改动计算公式、数据保存或云端业务。

## 验收方法

- 使用桌面正式构建产物，不以开发环境临时注入的样式作为最终通过依据。
- 独立浏览器运行真实桌面页面组件，网络、账号、原生桥和更新状态均为合成夹具。外部业务请求被拦截，没有向生产账号写入数据，也没有安装更新。
- 覆盖浅色、深色、窄窗口、高缩放、详情打开、筛选弹层、设置分类、反馈、更新下载/异常/重启取消等场景。
- 除截图目视检查，还验证文档/控件横向溢出、标题内容边界、弹层边界、按钮可达性、无重复提示和焦点返回。
- 依照 React 组件检查规范复核 effect 清理、稳定回调、模态焦点和桌面构建隔离，没有引入新的视觉组件依赖。
