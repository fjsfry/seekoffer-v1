# 寻鹿桌面端 Image2 统一视觉方案

日期：2026-08-11

## 设计原则

- 用寻鹿网站确定品牌：`#17494d` 深青绿、`#122026` 深色文字、`#f7faf9` 页面底色、暖白工作面。
- 用成熟 Windows 产品确定交互：固定标题栏和导航、连续列表、主从分栏、可调整宽度、独立滚动、稳定焦点和键盘状态。
- 数据页面不使用营销 Hero、卡片瀑布、巨大圆角、玻璃拟态或大面积渐变。
- 每个区域只保留一个主要行动；当前下一步优先于统计数字。
- 字体阶梯固定为 24 / 20 / 17 / 15 / 14 / 13 / 12px，业务正文不得小于 13px。

## 页面模型

### MasterDetailWorkspace

用于全部申请、通知详情和导师联系人。左侧主列表 360–480px，右侧详情 `minmax(0, 1fr)`；两侧独立滚动，宽度不足时切换为抽屉或返回式详情。

### DirectoryWorkspace

用于通知库、院校库、资源库和竞赛库。结构固定为页头、搜索筛选、连续结果行；有详情时使用主从分栏，不再使用悬浮大卡。

### UtilityWorkspace

用于日程、设置、GPA、帮助和法律信息。统一页头和内容起点；设置使用分类栏，日程使用月历和日程侧栏，阅读页限制正文宽度。

## 统一状态

- 首次加载：静态结构占位或单一 spinner，不使用 shimmer。
- 后台刷新：保留旧内容，只在工具栏展示同步状态。
- 空数据：32px 图标、14px 标题、13px 说明、一个 40px 行动。
- 硬错误：说明、重试、缓存边界明确；不与空状态同时出现。
- 过期数据：使用不遮挡内容的轻提示条。

## 验收矩阵

- 1440×900：80 / 100 / 125 / 150 / 175 / 200%。
- 1120×720：100 / 150 / 175 / 200%。
- 960×640：100 / 150 / 200%。
- 检查所有页面无横向溢出、正文不小于 13px、焦点不裁切、滚动归属唯一、主按钮不超过一个。
- 检查 loading / data / empty / stale / error / disabled / focus / pressed / drawer / dialog。

Image2 位图仅作为布局与视觉基准；所有文字、列表、输入、按钮和状态仍由真实 React / HTML / CSS 实现。
