# 桌面 v0.2.29 发布验收范围

本版对应 2026-10-09 的桌面 UI、更新提示、窄窗口与高缩放浮层修复。实现、合成测试方法及前端证据见 [桌面端全页面 UI 修复与验收](desktop-ui-audit-20261009.md)。该报告记录的是版本提升前的前端验收阶段，不是 v0.2.29 安装包的发布证明。

保留现有应用标识、窗口最小尺寸、用户数据模型及 updater 公钥。窄内容区使用自然纵向滚动，不能隐藏操作控件来换取“无溢出”。本轮未重新验收真实账号授权、Windows 覆盖安装、系统通知投递、真实云端写入或长期离线恢复，不将合成浏览器检查等同于原生安装与业务端到端验收。

## 本次授权与发布约束

2026-10-09，用户要求将本轮桌面修复推送线上，沿用此前明确授权的未签 Windows 发布者兼容流程。本次独立授权组装仅适用于 v0.2.29；不放宽严格 Stable CI 和通用签名门禁的证书要求，不修改更新签名公钥，也不覆盖任何历史公开版本。

- 新版本使用 `desktop-v0.2.29` annotated Tag；干净源码提交、构建记录和标签必须一致。
- 保留原始 internal-test 构建记录，独立组装公开副本；必须核对真实 `NotSigned` 状态、Minisign、SHA-256 和版本单调递增。
- GitHub 草稿资产下载回读通过并公开可用后，才提升经过验证的独立更新站候选；保留历史版本化文件。
- 此桌面包不包含网页版、数据库或业务数据部署；官网下载安装信息如需更新，按独立流程验证。

## 验证范围与限制

本轮 UI 修复已对桌面前端编译产物进行合成浏览器回归，覆盖浅深主题、窄窗口、高缩放、筛选浮层、设置分类、更新提示和重启取消。网络、账号、原生桥及更新状态使用测试夹具，没有安装更新或写入真实业务数据。

这些检查不代表本轮已完成真实账号授权、Windows 覆盖安装、系统通知投递、真实云端写入或长期离线恢复验收。v0.2.29 的最终干净构建、安装包验签、草稿回读和线上发布结果须另行记录，不沿用旧安装包哈希或把源码准备视作已发布。

最终产物及发布回读证据保存在项目内 `artifacts/desktop-release-v0.2.29/`，不包含密钥或私人账号资料。发布前重新验证最终构建，GitHub 草稿及公开目标、独立 Vercel 候选与正式域名分别回读；没有这些证据时不得声称 0.2.29 已发布或真实客户端已升级。

## 发布前弹层回归补充

首个本地候选在 200% 缩放的日程新建表单中暴露了真实时序问题：分类弹层切换到优先级时，外层滚动事件会在下一次 Escape 前提前关闭优先级弹层，导致 Escape 误关闭详情。该候选及其安装包没有发布，已保存于 `releases/seekoffer-desktop/preflight-v0.2.29-1-not-published/`。

最终修复让可见锚点在外层滚动/窗口调整时以合并的 `requestAnimationFrame` 重新定位，内部滚动不关闭弹层；焦点同步返回且使用 `preventScroll`，首个 Escape 只处理真实打开的弹层。`scripts/verify-desktop-schedule-popovers-20261009.mjs` 使用最终 `.next-desktop` 在 1440×900、960×640 的 200% 缩放下连续切换分类/优先级，实际等待弹层保持打开、检查外部滚动与尺寸调整、并验证两次 Escape 的关闭顺序；本次通过 94 项检查、无页面错误、无写入请求。该浏览器验收仍是合成环境，不替代真实 Windows 原生覆盖安装。
