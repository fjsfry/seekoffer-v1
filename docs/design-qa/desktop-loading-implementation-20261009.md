## 交付

- `DesktopLoadingIndicator`：16 / 24 / 30px 共享细线圆环，1050ms 匀速旋转；可延迟 180ms 淡入，但不会延迟实际数据展示。
- `DesktopLoadingState`：申请、通知、日程、导师、资源、帮助、设置和详情八类内容占位；低对比中性灰、无闪光条纹，不引入动画库或远程资源。
- 原生启动页与 React 启动态统一静态品牌、圆环及文字层级。授权交接明确区分浏览器等待和账号同步，阶段依据真实异步结果更新，不显示虚构百分比。
- 初次读取与真实空结果分开；读取失败停止骨架并给出重试。已有内容在后台同步时保持可用；院校目录无需等待云端统计即可浏览。
- 日程/导师读取状态按当前账号隔离，不用“保存成功”推断“已完成读取”，保留原有同步竞态防护。
- 保存、加入申请等操作统一小型反馈，增加忙碌态和重复提交保护；无法确认写入后读取结果时使用“暂未确认结果”，避免错误声称未保存。
- 修复首次读取失败后退出账号仍被错误卡遮住登录入口的问题。
- 通知首载只保留一个主要圆环，右侧使用安静占位；缩窄后日程页标题仍靠左。
- 兼容深色主题、系统减少动态及应用内减少动态设置，装饰占位不重复朗读。

实现遵循 React 最佳实践：旋转动画放在包裹元素上，使用明确的 effect 依赖和异步生命周期保护；不为短动画增加依赖或阻塞真实内容。
