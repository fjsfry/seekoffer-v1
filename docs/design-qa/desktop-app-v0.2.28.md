# 桌面 v0.2.28 发布验收范围

本版基于 `0443ee7` 登录/数据恢复及 `74db3f3` 加载体验改造，版本记录同步至 0.2.28。功能与实际验收细节分别见：

- [0.2.27 恢复验收](desktop-app-v0.2.27.md)
- [加载体验实现及验收](desktop-loading-implementation-20261009.md)

已经完成的源码/独立原生应用检查：全量桌面测试 808 通过、2 跳过；实际原生窗口登录恢复及主要页面数据读取；合成浏览器的首次加载、静默刷新、失败重试、960px/125% 缩放、深色及减少动态效果。新版本构建与发布字节另行核验，不沿用旧安装包哈希。

本次用户已明确授权沿用 0.2.22 的未签 Windows 发布者兼容发布流程；原 Stable CI 证书门槛不变。新的公开候选必须校验 Git 提交与精确版本标签、最终包 Minisign、SHA-256、`NotSigned` 实际状态、线上版本单调递增及历史资产完整性。候选站点验证后再切换独立更新站点，不部署网页版。

未覆盖的验收：使用真实私人资料的新建/编辑云端写入、长期离线重连、用户当前正式安装的交互式覆盖安装。本次发布不能把合成测试或签名验证等同于这些场景。

最终产物及线上回读证据保存到项目内 `artifacts/desktop-release-v0.2.28/`，不得包括密钥或私人账号资料。
