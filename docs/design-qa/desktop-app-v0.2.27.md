# 桌面端 0.2.27 恢复验收记录

日期：2026-10-09。状态：候选验证中，未发布。

## 问题与修复范围

旧版桌面端沿用已失效的通知和院校接口；账号授权需要更新时，缓存身份与云端连接状态不一致，用户缺少可用恢复入口。工作台同步和资源入口也需要对齐当前网站。

本候选恢复公开接口、登录重授权、退出、账号隔离、缓存错误反馈、完整截止筛选和日程/导师保存，并更新资源入口。七天重新授权策略、DPAPI凭据存储和按用户隔离的本地资料保持有效。

## 安装包约束

`scripts/bundle-desktop-recovery-candidate.ps1` 仅在版本、正式应用标识、当前页面指纹和本轮原生证据全部匹配后允许构建内部NSIS安装包；它只运行bundler，不触发Next/Cargo编译。生产可执行文件不得包含远程调试启动参数或合成验收数据。签名密码仅在bundler子进程环境中短暂存在，结束后清理引用与原生缓冲。

该辅助脚本明确拒绝Stable用途。正式发布继续执行原有签名、证书、更新清单、源码和版本门禁。

本轮已生成 `src-tauri/target/release/bundle/nsis/寻鹿 SeekOffer_0.2.27_x64-setup.exe` 及同名 `.sig` 更新签名文件。Rust `verify_updater_signature` 已对候选安装包和更新签名完成实际 Minisign 验证并通过。Windows Authenticode 检查仍为 `NotSigned`：更新签名与 Windows 发布者代码签名是两个独立检查，前者通过不能替代后者。它们仍是内部候选产物，未据此宣称完成安装验收或公开发布。
