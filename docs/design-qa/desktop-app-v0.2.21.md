# SeekOffer Desktop v0.2.21 产品级 UI 与安装体验 QA

> 日期：2026-08-31。本合同以当前桌面端实际源码为准，覆盖共享 Shell、七个核心工作页面、帮助与设置、响应式回流、应用缩放、主题、动效、键盘可达性和 Windows 发行体验。

## 设计系统合同

- 字体使用 `Segoe UI Variable`、`Microsoft YaHei UI` 和系统中文回退；不从网页下载字体。
- 页面、模块、卡片、正文和元数据遵循共享字阶与行高，普通可读文字不低于 `12px`。
- 浅色和深色主题使用语义颜色；寻鹿绿是唯一品牌交互色，不复制飞书、QQ 的商标、图标或专有资源。
- 卡片、控件、弹层与浮层使用统一圆角、边框、阴影和层级，不依靠随机渐变制造层次。
- 交互反馈使用 `83 / 167 / 250ms` 三档；减少动态效果时取消位移、缩放和非必要动画。
- Hover、Pressed 与 Focus 不得引起布局抖动；键盘焦点必须可见。

## 终止规则

源码测试、浏览器矩阵、静态导出和无签名 NSIS 编译都不等于正式发布。只有不可变源码标签、依赖安全、真实 Release 安装包、Tauri Minisign、有效 Authenticode、候选下载回读、真实 Windows 安装验收和生产 updater 复核全部通过，才能把 v0.2.21 标记为稳定版。
