# 寻鹿桌面端交互系统 v0.1.4

## 产品基线

寻鹿桌面端采用“单主窗口、工作台主线、任务支线”的结构。默认首页始终是“我的工作台”，并直接列出当前账号的全部申请项目；“我的一天”只承接当天事项，不与工作台争夺首页地位。

本版参考 Windows NavigationView、Fluent Motion、Todoist、Notion 与 Slack 的桌面交互规律，但不照搬任何一款产品：

- [Windows NavigationView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/navigationview)
- [Windows 标题栏](https://learn.microsoft.com/en-us/windows/apps/develop/title-bar)
- [Fluent 动效时长与缓动](https://learn.microsoft.com/en-us/windows/apps/design/motion/timing-and-easing)
- [Windows 应用通知](https://learn.microsoft.com/en-us/windows/apps/develop/notifications/app-notifications/app-notifications-content)
- [Todoist 桌面快捷键](https://www.todoist.com/help/articles/use-keyboard-shortcuts-in-todoist-Wyovn2)
- [Notion 搜索](https://www.notion.com/help/search)
- [Slack 缩放](https://slack.com/help/articles/236067467-Adjust-your-zoom-level-in-Slack)

## 1. 启动与登录

状态顺序固定为：

1. 原生启动页：显示品牌、非确定进度轨道和“正在启动寻鹿”。
2. 恢复登录状态：继续显示品牌加载页，不出现白屏。
3. 未登录：进入正式账号登录页。
4. 已登录：同步申请与工作台状态后进入首页。
5. 超过 8 秒：展示可理解的慢连接状态和“重新尝试”。

行为规则：

- 登录页与启动页在首次绘制前读取已保存的缩放和减少动态效果偏好。
- 登录中使用阻塞状态，按钮保持原宽，文案改为“正在处理…”，防止布局跳动。
- 密码登录和验证码登录使用完整 tab 语义、方向键切换和单一 Tab 停靠点。
- 错误就地显示在表单中，不抖动、不使用整页警告。
- 登录成功只进入工作台；不允许匿名或游客会话绕过门禁。

## 2. 主窗口与窗口行为

主窗口由自定义标题栏、浅层导航、内容区和状态栏组成。

- 标题栏空白区域可拖动；双击切换最大化与还原。
- 搜索、同步、账号和窗口控制按钮全部排除拖动命中。
- 保留最小化、最大化/还原、关闭和窗口状态恢复。
- 默认单主窗口，避免同一申请在多个窗口同时编辑产生冲突。
- 独立详情窗口、通知原文窗口和材料预览窗口列为后续能力，不在本版制造伪多窗口。

窗口自适应：

- 宽屏：232px 文字侧栏、申请列表、右侧详情检查器。
- 中等窗口：214px 侧栏，详情切为抽屉。
- 窄窗口或 150% 以上缩放：72px 图标栏，详情固定为带遮罩的模态抽屉。
- 最小支持窗口为 1120×720；任何缩放档位都不得让窗口控制、搜索入口或主操作被裁切。

## 3. 导航与历史

常驻主导航仅保留两组高频入口：

- 申请管理：申请工作台、日程与提醒、导师联系。
- 信息与资源：通知库、院校库、资源中心。

工具箱、帮助与反馈、设置固定在侧栏底部，不增加业务层级。

行为规则：

- 单击导航：进入目标页面，内容区回到顶部。
- 后退/前进：恢复每个路由在桌面内容容器中的滚动位置。
- 设置是应用层页面，不伪装成业务导航；`Ctrl+,` 打开后焦点进入返回按钮。
- 路由切换时标题栏和侧栏保持稳定，只更新内容区。
- 快速路由不闪进度条；持续超过约 120ms 时才显示顶部非确定进度。

## 4. 工作台主任务

工作台是申请项目的唯一总览与轻编辑入口。

### 列表

- 默认显示全部申请，不截断为“推荐”或“近期”子集。
- 提供范围、类型、状态、排序和当前列表搜索。
- `Ctrl+F` 聚焦工作台搜索；`Ctrl+K` 始终属于全局命令。
- 列表使用可选 grid 语义，方向键、Home/End 移动行焦点。
- `Space` 选择并查看详情；`Enter` 打开项目；双击是鼠标增强。
- 加载区声明 `aria-busy`，并播报加载、成功或使用最近数据的状态。

### 详情检查器

- 宽屏中固定在右侧，切换项目不丢列表筛选和滚动位置。
- 中小窗口中改为模态抽屉；打开后焦点进入关闭按钮，Tab 被限制在抽屉内。
- Esc、遮罩或关闭按钮退出，并把焦点送回刚才的项目行。
- 项目状态与材料勾选采用乐观更新：界面立即变化，后台保存。
- 保存成功显示全局轻提示；保存失败自动回滚并明确提示重试。

### 数据可信度

- 申请、日程与导师数据按正式账号 `userId` 分区，本机换账号不会继承上一账号数据。
- 旧版全局缓存只迁移一次，迁移后删除旧键。
- 日程使用更新时间解决多端修改；显式“未完成”可覆盖旧的完成状态。
- 删除日程使用 tombstone，防止离线旧设备重新把已删除事项合并回来。

## 5. 我的日程与快速新增

“我的一天”只承接当天执行，不复制工作台总览。

- 日期条支持前后移动与“回到今天”。
- 快速新增记录触发器，打开后焦点进入事项输入框。
- 模态弹窗具有背景 inert、Tab 循环、Esc、遮罩关闭和焦点恢复。
- 创建成功后显示“事项已创建”；完成事项后提供“撤销”。
- 本机保存先完成，云端同步随后进行；同步失败明确说明“已保存在当前设备”。

## 6. 全局搜索与命令

顶部只有一个全局入口：“搜索申请、学校、通知或命令”，快捷键 `Ctrl+K` 或 `F1`。

空查询时显示：

- 最近/当前账号申请项目。
- 工作台、我的一天、提醒中心、设置等常用动作。
- 高频信息与资源页面。

输入查询后：

- 同时检索申请学校、院系、项目名、申请状态和功能页面。
- 没有直接结果时提供“在通知库搜索该关键词”。
- 结果按申请项目、常用操作、信息与资源、申请管理、社区与帮助分组。
- 上下键选择，Home/End 跳转，Enter 执行，Esc 从面板任意焦点位置关闭。
- 打开快捷键说明后，关闭焦点返回顶部搜索入口，而不是返回已卸载的按钮。

## 7. 通知与反馈层级

采用三级通知：

1. Windows 横幅：截止临近、材料风险、通知变化等高价值事件。
2. 应用内提醒中心：保存未读、全部、稍后提醒和分类状态。
3. 底部状态栏：同步中、已同步、同步失败和当前设备状态。

本版边界：Windows 横幅只在寻鹿运行期间请求发送。应用完全退出后不承诺后台定时提醒；托盘常驻、后台调度和通知点击深链需在后续原生版本实现后再开放文案。

全局轻提示用于动作结果：

- 位置固定在右下角状态栏上方。
- 成功、警告、错误使用不同边框与图标，但不大面积染色。
- 默认 2.6–3.6 秒自动关闭；鼠标悬停暂停计时。
- 完成类操作可以带“撤销”；错误类提示保持更久。
- 页面内能够修复的错误仍就地显示，不用 Toast 代替字段错误。

## 8. 设置

设置只有四类：常规、通知、外观与无障碍、关于。

- 更改即时生效并保存到当前设备。
- 设置分类支持上下键和 Home/End。
- 开机启动、Windows 通知权限和测试通知必须显示真实系统结果。
- 恢复默认设置需要二次确认；确认区出现时焦点进入“确认恢复”，取消或完成后返回原按钮。
- 缩放档位：80、90、100、110、125、150、175、200%。
- `Ctrl++`、`Ctrl+-`、`Ctrl+0` 与底部缩放控件行为一致。

## 9. 动效协议

| 场景 | 时长 | 表现 |
| --- | ---: | --- |
| 按钮按下、勾选、图标状态 | 83ms | 颜色、透明度、最大 0.985 微缩放 |
| 菜单、轻提示、Popover | 167ms | 透明度 + 4px 位移 |
| 对话框、详情抽屉、页面进入 | 250ms | 透明度 + 6–8px 位移 |
| 侧栏宽度与大范围布局 | 333ms | 位置和尺寸，不弹跳 |
| 列表选择与状态更新 | 167ms | 背景、指示条和内容 3px 位移 |

统一缓动：

- 进入：`cubic-bezier(0, 0, 0, 1)`。
- 退出：`cubic-bezier(1, 0, 1, 1)`。
- 已有元素换位：`cubic-bezier(0.55, 0.55, 0, 1)`。

禁止项：

- 不用弹簧过冲、卡片逐个长时间 stagger、持续呼吸文字或左右抖动错误。
- 不动画 `width/height/top/left` 的高频组件；优先 opacity 与 transform。
- 骨架动画只表达真实加载，不展示虚假百分比。

减少动态效果模式：

- 同时尊重 Windows `prefers-reduced-motion` 与寻鹿设备偏好。
- 启动、登录、工作台和弹层全部关闭循环、位移、缩放和闪烁动画。
- 保留即时颜色、边框、选中和完成状态，确保信息不依赖运动才能理解。

## 10. 拖拽边界

本版已实现窗口标题栏拖动。业务拖拽只在以下对象具备稳定数据模型和键盘替代后开放：

- 材料文件从资源管理器拖入申请。
- 自定义事项与材料通过拖动手柄排序。
- 手动排序模式下移动项目。

申请阶段、审核结果、自动排序列表和导航入口不允许拖拽。任何未来拖拽都必须同时提供“上移/下移/移动到”菜单、Esc 取消、合法投放线和完成后的撤销。

## 11. 键盘基线

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl+K` / `F1` | 全局搜索与命令 |
| `Ctrl+F` | 当前工作台列表搜索 |
| `Ctrl+N` | 前往通知库添加申请项目 |
| `Ctrl+,` | 打开设置 |
| `Alt+← / Alt+→` | 后退 / 前进并恢复滚动位置 |
| `F6 / Shift+F6` | 标题栏、侧栏、内容区循环 |
| `Ctrl++ / Ctrl+- / Ctrl+0` | 放大、缩小、恢复 100% |
| `Ctrl+/` | 快捷键说明 |
| `Esc` | 关闭最上层弹层或取消当前临时操作 |

## 12. 发布门槛

发布前必须验证：

- 1440×900 与 1120×720。
- 80/100/125/150/175/200% 缩放。
- 登录、工作台、命令面板、通知中心、详情抽屉、快速新增和设置。
- 鼠标、键盘、减少动态效果和高对比度模式。
- 原生拖动、最大化/还原、窗口状态恢复、Windows 横幅与开机启动。

代码签名、自动更新、托盘后台通知、单实例深链和材料拖入仍是公开发布前的原生工程项；它们不应在界面文案中被提前承诺。
