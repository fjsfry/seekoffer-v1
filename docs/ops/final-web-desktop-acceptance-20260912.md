## 测试过程中的限制与纠正

1. 初版验收脚本对权益接口误用 GET，返回 405；查明正式客户端使用只读 POST `get-entitlement` 后复核 200。这不是产品权限或停服故障。
2. 排序测试最初选中了未展开面板内的控件；改用用户可见的排序按钮后通过。
3. 网页合成测试首次等待同步提示 12 秒超时，独立复跑完成全部 36 次合成请求且无 JS 异常；保留这一观测，不声称冷启动耗时得到保证。
4. 下载 HEAD 没有 `Content-Length`，因此本轮仅确认链接可达；完整体积与 SHA 采用 22:22 已执行的下载校验及本轮重新核实的相同 Worker 版本，没有伪造 HEAD 体积检查。
5. Windows 控件自动化额外搜索输入遇到几何/属性兼容错误，未将原生搜索、翻页输入标为本轮实机通过。已观察真实申请/通知界面；通知查询与故障协议另有网页、编译桌面和此前独立原生传输测试证据。

- 新一轮真实密码登录、注册/找回邮件发送：本轮未重新执行，沿用此前人工验证；仅当前已登录会话和新页面登录流程得到本轮检查。
- 实际系统休眠、托盘提醒送达、完整跨机器加密档案恢复：尚未完成实机验收。
