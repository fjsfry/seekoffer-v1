# 寻鹿 SeekOffer 桌面端 v0.2.22 发布说明

> 日期：2026-09-01。基线版本为 v0.2.21。本版本只包含已经从当前工作区精确隔离并验证的桌面通知卡片节奏与公共通知加载优化；网站后台、支付、公众号、浏览器扩展和其他未提交工作不属于本次发行。

## 本版改进

### 通知卡片更紧凑

- 通知库卡片改为由内容自然撑高，不再依赖固定最小高度。
- 截止信息和“查看详情 / 加入申请”操作组整体上移，缩短信息与操作之间的无效空白。
- 宽窗口、窄窗口以及 100%–200% 缩放下，按钮保持在卡片内，正文与操作区不相交。

### 院校库与通知库加载更快

- 公共通知数据使用进程内 stale-while-revalidate 快照：进入院校库、通知库和提醒中心时优先立即显示最近一次有效数据，再在后台静默校验。
- 共享 5 分钟新鲜期与 15 秒失败重试窗口，跨页面复用同一进行中的请求，避免每次切换页面重复等待同一批云端数据。
- 网络失败时保留上次成功数据；没有远端快照时才使用本地兜底；远端返回空列表时尊重该权威结果，不把旧兜底重新混入。
- 页面不可见或设备离线时，提醒中心不会进行无意义的周期刷新。
- 此缓存仅保存公开通知，不保存申请、联系人或其他用户私有数据。

## 发行边界

- 本版延续用户已经确认的“暂不配置 Authenticode 证书”决策。Windows 可能显示“未知发布者”或 SmartScreen 提示；安装包的 Authenticode 状态将如实记录为 `NotSigned`。
- Tauri updater 的 Minisign 签名仍是强制门禁；安装包、`.sig`、`latest.json`、`SHA256SUMS.txt` 与 `build-info.json` 必须在发布前一次生成并形成闭合证据。
- Tauri updater 签名只用于验证更新包完整性，不能替代 Windows 发布者证书。
- v0.2.21 的发布资产不会被回写；本次使用新版本号与新标签 `desktop-v0.2.22`。
- 当前稳定基线是 v0.2.21；更新器必须只允许 v0.2.21 → v0.2.22 的单调提升，并保留历史版本化资产。
