# 寻鹿 SeekOffer 桌面端 v0.2.29

本版优化桌面更新提示、页面排版，以及窄窗口和高缩放下的弹窗体验。

## 本版改进

- 修复更新提示的定位和按钮布局，在右上角独立显示；设置页直接展示更新状态，减少重复提示。
- 改善更新重启确认框的取消与焦点返回行为；实际安装更新仍需用户确认，不强制退出正在运行的客户端。
- 优化窄窗口及高缩放下的申请、日程、导师、通知、院校、资源和设置页面布局，避免标题、工具栏及输入控件挤压。
- 统一院校和日程筛选弹层的缩放坐标与视口边界；限制全局搜索、快捷键对话框的高度，保留内部滚动和关闭操作。
- 修复 GPA 工具标签、汇总和截止提醒页面的溢出或重叠；保持完整文字与自然纵向滚动，不改变计算公式、数据保存或云端业务逻辑。
- 统一通知详情的加载、异常状态与桌面标题样式。

## 安装与更新说明

安装包暂未配置 Windows Authenticode 发布者证书，Windows 可能提示“未知发布者”。桌面自动更新仍保留安装包签名校验。

仅从寻鹿官方下载入口获取安装包。安装前保存正在编辑的内容；更新后可在“设置 → 关于与更新”确认版本。
