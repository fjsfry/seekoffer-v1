# 寻鹿桌面端 0.2.27 候选版本

状态：内部验收候选，尚未正式发布。发布日期待定。

本轮恢复新版寻鹿网站调整后的桌面登录、通知、院校和工作台数据链路。

## 主要改进

- 通知列表、详情及院校筛选改用当前公开接口；院校统计使用完整服务端统计。
- 修复授权到期后仍显示缓存账号却无法同步的问题。需要重新授权时直接显示重新登录入口，本机资料与未同步修改保留。
- 修复退出登录依赖旧会话的问题。授权过期或断网时仍可退出本机账号。
- 区分服务异常、正常零结果和缓存数据，提供明确的重试反馈。
- 截止事项使用服务端筛选与有界分页，避免只检查通知第一页导致遗漏。
- 修复日程、导师等工作台修改的云端写入与确认状态；遇到其他设备更新时保留本地修改并核对版本。
- 资源中心更新为当前资料商城、已购资料和账号权益入口；浏览器中继续完成需要完整网页流程的操作。
- 本地开发预览使用独立应用标识，隔离正式应用资料。

## 候选包与发布边界

候选安装包版本为 `0.2.27`，正式应用标识仍为 `com.seekoffer.desktop`。本地打包辅助脚本仅支持 `internal-test`，只将签名凭据传给 Tauri bundler 子进程。它不会编译、上传、部署、更新下载页或切换自动更新清单。

验收必须使用当前编译页面指纹对应的浏览器回归报告，以及新隔离原生应用生成的公开接口探针。旧版本报告不能充当本版本验收证据。完整校验项目见 [设计与验收记录](../design-qa/desktop-app-v0.2.27.md)。
