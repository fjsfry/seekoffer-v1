# 寻鹿 SeekOffer 桌面端 v0.2.21 候选说明

> 日期：2026-08-31。v0.2.21 是在 v0.2.20 内部候选之后重新从当前源码构建的正式发布候选。它不会复用 2026-08-29 的旧安装包，也不会在签名、真实安装和生产更新门禁完成前被描述为已正式上线。

## 本版目标

- 以通知库为统一密度基准，保留现有信息架构，统一全部申请、日程提醒、导师联系、院校库、资源中心、帮助与反馈及设置的字体、控件、卡片、留白和交互反馈。
- 在桌面窗口缩放、系统 DPI 与应用缩放组合变化时保持信息可达，避免内容相交、横向截断、面板零高度和详情展开后主列表变形。
- 用新的版本号取代已经用于内部验收的 v0.2.20，避免同版本更新器无法识别新二进制。
- 修复发布前依赖审计发现的高危依赖，重新锁定构建输入。

## 产品与交互

- 统一 Windows 字体栈、寻鹿品牌绿、语义文字色、圆角、边框、阴影与 `83 / 167 / 250ms` 动效节奏。
- 全部申请卡、日程事项、导师联系人、通知、院校与资源卡使用一致的身份区、事实区和操作区层级。
- 宽窗口保持高效信息密度；窄窗口和高缩放下自然回流，不隐藏核心操作，也不依赖水平滚动读取主要内容。
- 侧栏入口始终显示图标和文字；帮助与设置与主导航保持稳定分区。
- Hover、Pressed、Focus、Selected、Disabled、Loading、Success、Error 与 Undo 状态保持可感知且不改变组件几何尺寸。
- 尊重系统减少动态效果、浅色/深色主题和键盘焦点可见性。

## 安全更新

- Next.js 最低版本提升到已包含 2026 年 7 月安全修复的 `15.5.21`，锁文件解析到更新的同系列补丁版本。
- PostCSS 提升到 `8.5.26`，修复 previous source map 自动加载相关路径问题。
- Sharp 提升到 `0.35.4`，使用修复后的 libvips 依赖。
- Nano ID、brace-expansion 与 js-yaml 的间接依赖均锁定到修补版本。
- 正式发行只接受官方 npm registry 的完整审计结果；不会使用 `--force` 绕过不兼容升级。
- 新增 fail-closed updater-site 组装器：保留生产历史资产，只允许已验签 Stable 候选单调提升根/Stable 清单，拒绝内部包、同版本覆盖、哈希漂移和策略漂移。

## 发布边界

- Tauri updater 私钥、Windows 证书和密码只允许存在于受保护的发行环境，不进入 Git、前端产物、日志或发布说明。
- Tauri `.sig` 用于更新包完整性，不能替代 Windows Authenticode 可信发布者签名。
- 旧 v0.2.20 内部安装包只作为历史证据保留，不复制、重命名或提升为 v0.2.21。
- 在所有未勾选门禁完成前，v0.2.21 只能称为候选版，生产更新通道继续保持 v0.2.19。
