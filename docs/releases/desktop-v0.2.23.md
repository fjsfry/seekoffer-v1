# 寻鹿 SeekOffer 0.2.23 候选版

本次迁移版使用 Clerk 登录与 D1 云同步，原业务用户编号、本机申请与加密凭据保留。系统浏览器完成登录后可回到桌面工作台；申请备注可在网站与桌面之间同步。断网或额度不足时保留待同步内容，重试会核对云端版本，避免覆盖其他设备的新修改。

这是 2026-09-11 构建的 internal-test 候选包，尚未公开发布。用户已在此前本机迁移版确认登录及备注双向同步；新包的静态页面与合成数据测试另行记录，不能替代每一台真实设备的验收。

原 Supabase 安装版不会因为网站更新而自动接入 D1。正式更新清单尚未切换，支付、邮件发送和生产域名不在本安装包准备操作中变更。安装包的更新签名与 Windows Authenticode 是两项检查；当前尚不具备 Stable 要求的 Windows 证书。
