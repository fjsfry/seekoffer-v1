# 寻鹿 SeekOffer 桌面端 v0.2.28

本版恢复新版网站调整后的桌面登录与数据链路，并统一页面加载体验。仅发布桌面客户端，不改变网页版部署。

## 本版改进

- 在系统浏览器授权登录后安全返回桌面工作台，修复旧版登录及云端数据加载失败。
- 通知、院校和工作台接入当前数据接口；授权过期时提供重新登录入口，保留本机资料与未同步修改。
- 统一启动、登录、应用列表、日程、导师、通知、院校、资源与设置的加载反馈；使用克制的旋转指示与匹配内容布局的骨架屏。
- 后台刷新时保留已有内容，不再把正在加载误显示为空数据；网络失败时结束等待并提供重试。
- 补齐深浅主题、减少动态效果及窄窗口缩放适配。
- 更新 Next.js、图像处理与 source-map 构建依赖的安全补丁；不改变网站线上部署。

## 安装与更新说明

本版沿用此前经产品负责人确认的发布方式：安装包没有 Windows Authenticode 发布者证书，Windows 可能提示“未知发布者”。Tauri Minisign 更新签名仍须通过真实密码学验证，不能关闭或跳过。

仅从寻鹿官方下载入口获取安装包。安装前保存正在编辑的内容；本次发布不强制退出正在运行的客户端。更新后可在“设置 → 关于与更新”确认版本。

## 本次授权及发布范围

2026-10-09，产品负责人在明确获知证书缺失及正式 CI 门槛后，授权“先按我们原来的流程走”。此授权限定为本次 v0.2.28 未签 Windows 发布者的兼容发布，不放宽现有 Stable CI 的证书要求，也不更改更新签名公钥。

- 采用全新版本、不可变标签 `desktop-v0.2.28` 与新安装包；不得覆盖 0.2.27 内测包或任何历史公开资产。
- 现有内部打包产物不修改；独立组装经明确授权的公开候选，保留原始来源、哈希及未签发布者状态。
- 验证 GitHub 公开下载字节、更新签名和候选更新站点后，才切换原更新地址；保留历史版本化文件。
- 网页主站、数据库、业务数据和现有用户客户端不在本次部署修改范围。

## 验证范围

此前功能验收已完成：808 项测试通过、2 项需显式启用的线上探测跳过；生产前端构建及浏览器加载/失败重试/主题/缩放回归通过。独立原生窗口已验证登录恢复及主要页面真实数据读取。

这些结果不代表全新安装、真实私人资料写入或长期离线重连的完整验收；本次发布记录须另行保存最终构建、签名与线上下载回读证据。
